# Xntrova_Assesment

Modern, responsive homepage redesign for Xntrova Technologies (Digital Marketing &amp; Tech Agency) built with semantic HTML5, modern CSS3 variables, and vanilla JavaScript. Features dark/light mode, multi-column mega menu, continuous marquees, left off-canvas drawer, and interactive conversion widgets.

**Xntrova Technologies - Homepage Redesign Assessment**

Overview:
Company: Xntrova Technologies
Assessment Type: Practical Website Development Assessment
Position: Web Developer
Live Website Reference: https://www.xntrova.com/
Technologies Used: HTML5, CSS3, Vanilla JavaScript

Project Summary:
This repository contains a full redesign and development of the Xntrova Technologies agency homepage. The objective was to modernize the user experience, improve conversion flow, and maintain the core brand identity while ensuring strict mobile responsiveness and clean code structure without any external frameworks.

Key Features and Major Changes:

Design and Theme Switching

A native dark and light mode toggle was implemented using CSS custom properties. The default theme is light, and the selected theme persists across page reloads using browser local storage.

Navigation and Header

The navigation includes a multi-column services mega menu organized into categories such as SEO Services, Performance Marketing, Social Media, Ecommerce, Studio, Marketing, and Web Development. It also includes an active region selector supporting India, Australia, Canada, the United States, and the United Kingdom.
Mobile Usability and Left Slide-In Drawer

On tablet and mobile screens, navigation overcrowding is resolved by an off-canvas navigation drawer that smoothly slides in from the left side of the screen. It features an interactive accordion for services, a backdrop overlay, and quick contact actions.
Conversion-Focused Hero Section

The hero area pairs a high-impact agency value proposition with an embedded Free Digital Audit lead capture form. All inputs are styled for accessibility and touch interaction.

Visual Enhancements and Smooth Animations

An animated orbital ecosystem diagram represents the agency process alongside a live performance overview widget. Continuous infinite marquees are built using pure CSS transform animations for the Reviews Platform badges, Trusted Companies logos, and a three-row Tools We Work With showcase.
Interactive Sections

Includes a touch-friendly client testimonial slider with review cards, expanding FAQ accordion components, an interactive floating assistant chat modal, and a direct WhatsApp contact trigger.

Directory Structure:

index.html: Semantic HTML5 document containing all sections and SEO metadata.

css/style.css: Core stylesheet containing design tokens, layout grids, components, animations, and responsive media queries.

js/main.js: Modular JavaScript managing theme toggling, drawer mechanics, sliders, country selection, accordions, and form submissions.

Zero broken images, using authentic high-resolution CDN assets and scalable vector icons.
Strict responsive breakpoints for desktop, tablet, and mobile screens.
Clean, maintainable code following modern web standards.
